# Provenance

phone-adb-control is the owner's confirmed original instruction/helper workflow. The owner approved MIT publication on 2026-11-03 under the public alias Asuna923.

The portable release removes the fixed device serial, machine-specific ADB path and real device artifacts. It requires an explicit serial for device operations and an explicit output file outside the installed skill. It rejects shell metacharacters in injected text and parses hierarchy output with surrounding warning text.

Only the selected instruction, helper and UI metadata were taken from the local installation. No prior repository history, device apps or third-party binaries are included. Android Platform Tools are an external dependency; this repository's license does not relicense them.

The author attribution and MIT notice travel with each independent skill installation through the included LICENSE file.
